# 数据接口

## 视觉 JSONL

`vision/src/depth_estimation/demo_video.py` 可写出：

- `--result-jsonl`：带时间戳的检测结果、三维位置和三维速度；
- `--frame-jsonl`：每一帧双目图像对应的一条时间戳记录；
- `--record-raw`：未经修改的左右目拼接原始帧；
- `--record-monitor`：带标注的监控视频。

控制器持续读取结果 JSONL，并拒绝过期或不合理的测量值。后续生成的每套数据都应
同时保留采集时间戳和处理时间戳。

结果记录的每个 `tracks[]` 元素包含 `position: [X, Y, Z]`（米）和
`velocity: [VX, VY, VZ]`（米/秒），均为相机坐标系下的目标相对状态。
速度由滤波后的图像中心变化率及深度变化率按针孔模型反投影得到；在图像中心
速度尚未建立或相机参数无效时，`velocity` 为 `null`，不表示目标静止。
当前控制器仍只读取 `position`，不会因新增字段改变控制行为。

## 坐标约定

- 相机：`[X 右, Y 下, Z 前]`，单位为米；
- 潜器机体：`[前, 右, 下]`，单位为米；
- yaw：绕机体向下轴、艇首向右旋转为正，单位为弧度；
- 力：`[前, 右, 下]`，单位为牛顿；
- yaw 力矩：单位为牛顿米。

## 下位机协议

当前上位机和下位机使用第 5 版协议。Python 协议实现与下位机结构体必须同步修改。
烧录或操作实机前，应分别运行上位机和下位机目录中的协议测试。
