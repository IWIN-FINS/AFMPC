# 模型二与 PDF 的对应关系

对照 `D:\浏览器下载\Untitled (1).pdf` 第 3-8 页，本实现固定采用 PDF 中“认为目标静止”的模型二：

```text
v_rel[k+1] = F v_rel[k] + G tau[k]
x[k+1]     = A_d x[k] + B_d tau[k]
```

## 已实现

- 固定线性阻尼的三轴 Fossen 平移模型及精确零阶保持离散化；
- 位置、相对速度、绝对综合力和力变化量代价；
- 独立的终端位置、终端速度权重倍率；两者相同时等价于原来的统一终端倍率；
- 综合力与力变化率硬约束；
- 前向距离、水平视场、垂直视场软约束；
- 只测相对位置、同时估计相对速度的卡尔曼滤波；
- FineSUB 现有上下两组混控矩阵与八推进器顺序；
- QP 失败和目标丢失时的限速安全回退。

## 相对 PDF 的工程化处理

- PDF 写出 `p[k+1]=p[k]+Ts*v[k+1]`；代码对联合 `[p,v]` 连续系统做精确零阶保持离散化。
- PDF 的欧氏距离下界是非凸约束；代码改为前向距离分量的软上下界，使优化保持为凸 QP。
- PDF 给出通用六维力和伪逆分配；代码继续使用 FineSUB 固件中的已核对混控矩阵，MPC 只输出三轴平移力。
- PDF 提到延时卡尔曼滤波；当前版本没有图像时间戳回溯和固定延时补偿。
- `tau_base` 不进入模型二预测、卡尔曼时间更新或模型二代价；模型二正常求解只使用绝对综合力 `tau`。
